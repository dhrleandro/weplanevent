Casas e chances

Peso relativo e quantidade de casas iguais. Ex.: peso 1 e quantidade 17 cria 17 casas idênticas na roleta sem precisar repetir a linha. Tipo define se a casa é prêmio (WIN), tente outra vez (RETRY) ou sem prêmio (FAIL). Todas as fatias têm o mesmo tamanho na tela, mas cada uma sai com a chance que você definir. A cor de casas WIN e RETRY pode ser escolhida no quadrado ao lado do nome; casas FAIL recebem cores automáticas, sempre diferentes entre si.

O trecho que decide o resultado

Num sistema real, essas linhas rodam no servidor e devolvem só o índice.

function sortear(itens) {
  const total = itens.reduce((s, i) => s + i.peso, 0);
  let r = Math.random() * total;
  return itens.findIndex(i => (r -= i.peso) < 0);
}

// a roleta só anima até quem já ganhou
